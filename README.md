## Daily Practice Structure

Each learning module will contain daily work:

```text
Module
│
├── README.md
├── day-01.md
├── day-01-programs.java
├── day-02.md
├── day-02-programs.java
└── ...
```

### `day-XX.md`

Contains:

* Theory
* Definitions
* Examples
* Important concepts
* Interview questions
* Key learnings
* Practice checklist

### `day-XX-programs.java`

Contains:

* Practical Java programs
* Logic-building exercises
* Topic-wise coding practice
* Corrected programs
