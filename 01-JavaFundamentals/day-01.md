## 1. What is Java?

Java is a high-level, object-oriented, class-based programming language developed by Sun Microsystems.

Java is widely used for:

* Web applications
* Backend development
* Enterprise applications
* Desktop applications
* Android applications

### Key Feature

Java follows the principle:

**Write Once, Run Anywhere (WORA).**

Java source code is compiled into bytecode, and the bytecode can run on different operating systems using a compatible JVM.

Important features of Java are:

1. Simple
2. Object-Oriented
3. Platform Independent
4. Secure
5. Robust
6. Portable
7. Multithreaded
8. Distributed
9. High Performance
10. Dynamic

## 3. JDK

**JDK = Java Development Kit**

JDK is used to develop Java applications.

It contains the tools required for Java development.

```text
JDK
│
├── JRE
│   └── JVM
│
└── Development Tools
    └── javac
```

### Important

`javac` is the Java compiler.

It converts Java source code into bytecode.

---

## 4. JRE

**JRE = Java Runtime Environment**

JRE provides the environment required to run Java applications.

```text
JRE
│
└── JVM
```

JRE contains the JVM and the libraries required for running Java applications.

---

## 5. JVM

**JVM = Java Virtual Machine**

JVM executes Java bytecode.

Main responsibilities include:

* Loading classes
* Verifying bytecode
* Executing bytecode
* Managing memory
* Garbage collection

---

## 6. Bytecode

Bytecode is the intermediate code generated by the Java compiler.

When we compile:

```text
Hello.java
```

using:

```text
javac Hello.java
```

the compiler generates:

```text
Hello.class
```

The `.class` file contains Java bytecode.

---

## 7. Java Execution Flow

The complete flow is:

```text
Java Source Code
       ↓
     javac
       ↓
    Bytecode
       ↓
    .class File
       ↓
      JVM
       ↓
 Machine Code
       ↓
    Execution
```

### Example

```java
public class Hello {

    public static void main(String[] args) {

        System.out.println("Hello Java");

    }
}
```

Save as:

```text
Hello.java
```

Compile:

```text
javac Hello.java
```

This generates:

```text
Hello.class
```

Run:

```text
java Hello
```

## 8. Variables

A variable is a named memory location used to store a value.

Example:

```java
int age = 29;
```

Here:

* `int` → data type
* `age` → variable name
* `29` → value

Another example:

```java
double salary = 50000.50;
```

---

## 9. Data Types

Java data types are divided into two major categories:

```text
Data Types
│
├── Primitive
│
└── Non-Primitive
```

### Primitive Data Types

Java has 8 primitive data types:

| Data Type | Example                     |
| --------- | --------------------------- |
| byte      | `byte b = 10;`              |
| short     | `short s = 100;`            |
| int       | `int age = 29;`             |
| long      | `long number = 100000L;`    |
| float     | `float price = 10.5f;`      |
| double    | `double salary = 50000.50;` |
| char      | `char grade = 'A';`         |
| boolean   | `boolean active = true;`    |

### Non-Primitive Data Types

Examples:

* String
* Array
* Class
* Interface
* Object

# Interview Questions

### Q1. What is Java?

Java is a high-level, object-oriented, class-based programming language.

### Q2. What is JDK?

JDK stands for Java Development Kit. It provides the tools required to develop Java applications.

### Q3. What is JRE?

JRE stands for Java Runtime Environment. It provides the environment required to run Java applications.

### Q4. What is JVM?

JVM stands for Java Virtual Machine. It executes Java bytecode.

### Q5. What is bytecode?

Bytecode is the intermediate code generated by the Java compiler and stored inside a `.class` file.

### Q6. Why is Java platform independent?

Java source code is compiled into platform-independent bytecode. A JVM available for the target operating system executes that bytecode.

### Q7. What is the difference between JDK, JRE and JVM?

```text
JDK → Development
JRE → Running Java applications
JVM → Executing bytecode
```
