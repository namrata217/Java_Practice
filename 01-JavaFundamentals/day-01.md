## 1. What is Java?

Java is a high-level, object-oriented, class-based programming language.

Java is widely used for:

- Web applications
- Backend development
- Enterprise applications
- Desktop applications
- Android applications

Java follows the principle:

**Write Once, Run Anywhere (WORA).**

---

## 2. Features of Java

Important features:

- Simple
- Object-Oriented
- Platform Independent
- Secure
- Robust
- Portable
- Multithreaded
- Distributed
- High Performance

Interview Questions
Q1. What is Java?

Java is a high-level, object-oriented, class-based programming language.

Q2. What is JDK?

JDK is the Java Development Kit used for developing Java applications.

Q3. What is JRE?

JRE provides the environment required to run Java applications.

Q4. What is JVM?

JVM executes Java bytecode.

Q5. What is bytecode?

Bytecode is the intermediate code generated by the Java compiler and stored in a .class file.

Q6. Why is Java platform independent?

Java source code is compiled into platform-independent bytecode, which can be executed by a JVM available for the target operating system.
